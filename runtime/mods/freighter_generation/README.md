# Rejected global S-class generation probe

An independently authored sparse EXML patch targeted `METADATA/REALITY/TABLES/INVENTORYTABLE.MBIN` from the pinned Steam build 179666 (`NMS.exe` SHA-256 `b7913f268dfc62386b6b68f524bfc8ade4a44a9f4fbad39085b7bf51be3680cb`). It is outside the requested per-offer freighter delivery. It is not installed, and the patch file was removed from this repository after its ordered-array targeting could not be validated. Game generation behavior remains unverified.

The intended changes were initial general/technology slot counts of 120/60 for all generated freighters and economy-wide S=100 class probabilities. The class change would be shared by other generated ships and multitools; it cannot be described as freighter-only. It would not change ownership, prices, offer context, installed technology, maximum upgrade bounds, or the four vanilla supercharged slots. Sparse EXML behavior for separate reward IDs does not establish correct targeting for nested inventory-table arrays.

For offline schema validation, the same fields were applied to a full copy of the exact-build `INVENTORYTABLE.MXML`. MBINCompiler 7.04.0.1 compiled it successfully and decompiled the generated MBIN. The round trip retained all three freighter entries at 120/120 general min/max and 60/60 technology min/max, with S probability 100 in all four economy groups. This validates the full-copy MBIN schema and serialization, not the game's runtime merge or freighter UI. A later sparse-file round trip demonstrated that named array entries can serialize into the first positions instead of their named positions. The sparse file was therefore removed.

The reference ZIPs supplied by the user contain Lua scripts and EXML change fragments, not installable PAK files. They were inspected as examples of relevant property names. This patch was independently authored from the installed build's extracted table; it does not bundle either third-party archive. The [Only S class](https://www.nexusmods.com/nomanssky/mods/2878) and [Square Super Charged Slots](https://www.nexusmods.com/nomanssky/mods/2879) pages restrict modification and redistribution of their assets. Do not add their files to this repository or application package.

The other tables those scripts mention serve different targets: `GCBUILDABLESHIPGLOBALS.GLOBAL.MBIN` changes buildable ships, while `GCFLEETGLOBALS.GLOBAL.MBIN` and `FRIGATETRAITTABLE.MBIN` change frigate generation. This freighter proof does not modify them.

The known-good currency DLL started the game to the menu after the rejected freighter-offer DLL was restored. With the game closed and no other loose inventory-table mod present, this data patch was briefly installed at `GAMEDATA/MODS/NMSCourierFreighterGeneration/METADATA/REALITY/TABLES/INVENTORYTABLE.EXML`; its installed SHA-256 matched the source (`a29acfaa18e8abc11ee27593a2c1119dffdf9e5b64b10342956769e779c4b98b`). Before any game-behavior test, the user clarified that global S-class generation was not the intended freighter-delivery behavior. After the process exited, the exact installed file and its empty mod directory were removed. No generated entity was inspected or accepted with this patch. Do not reinstall it for the per-offer delivery test. That flow needs an eligible native offer whose particular freighter is configured before acceptance, followed by UI, currency, ownership, and persistence checks.
